## Guardrails

### FORBIDDEN (Auto-Reject)
- ❌ Direct Meta API calls (`graph.facebook.com`) → Use `vilona_trakpro_engine` helpers
- ❌ Duplicate token loading (`os.getenv("META_ACCESS_TOKEN")`) → Import from engine
- ❌ Hardcoded paths (`/home/openclaw/...`) → Use `WORKSPACE`/`DATA_DIR` from engine
- ❌ Code files in root directory → Place in `server/`, `client/`, `scripts/`, `tests/`
- ❌ Throwaway test scripts in `scripts/` → Use `tests/` with Vitest/Playwright
- ❌ Raw SQL in routes/services → Use repositories
- ❌ `console.log` / `print()` in production → Use `server/lib/logger.js`
- ❌ Silent `catch (e) {}` → Throw typed errors
- ❌ Committing `data/*.json` → Auto-regenerated, gitignored
